# 旅行日记

一个记录旅行和攀岩活动的项目，包含微信小程序、云托管后端，以及独立的大连·丹东旅行地图网页。小程序的行程、路书和互动数据保存在 MySQL，可联网更新。

## 功能概览

- **发现行程**：搜索、筛选旅行，按日期查看行程、地图和野攀保险提示；支持报名、每日评论、分享和复制。
- **岩场路书**：搜索岩场，按区域查看介绍、线路图和路线说明，图片可放大。路书内容和图片从数据库读取。
- **我的收藏**：收藏旅行，收藏保存在当前设备。
- **个人主页**：填写微信头像和昵称，查看活动、攀爬次数、红点路线统计、累计趋势及路线回顾。
- **磕线记录**：在活动日期详情中记录岩场、路线、难度、攀爬方式、结果和可选心得；路线可搜索，未收录时可手动输入。

详细使用说明和统计口径见 [小程序 README](./xiaochengxu/README.md)；路书、线路目录及数据库发布步骤见 [云托管 README](./cloudrun/README.md)。

## 项目目录

| 路径 | 用途 |
| --- | --- |
| `xiaochengxu/` | 原生微信小程序，行程源数据在 `data/` |
| `cloudrun/` | Express 后端、MySQL 表结构、路书配置及发布脚本 |
| `plans/` | 旅行文字计划；`dalian-20261001/web/` 为静态网页发布目录 |
| `docs/` | 保险二维码源图、旅行封面和其他资料 |
| `AGENTS.md` | 旅行维护、保险提示和数据库发布规则 |

## 开发和发布

1. 用微信开发者工具导入 `xiaochengxu/` 并选择普通编译；后端独立部署，配置见 [云托管部署](./cloudrun/README.md)。
2. 修改旅行正文或日期后，在 `cloudrun/` 生成并发布行程数据；已有联网版本不需要为纯内容更新重新发布小程序。详见 [行程发布流程](./cloudrun/README.md#新增或修改旅行无需重新发版)。
3. 新增或更新路书时，按 [路书维护指南](./cloudrun/README.md#新增和更新路书)核对 PDF、整理分区和图片、发布数据库，并单独维护可搜索的线路目录。
4. 页面交互、包内图片或后端功能变更分别需要发布小程序或部署后端；数据库更新、Git 推送和网页部署不能互相代替。

静态网页可本地预览：

```sh
python3 -m http.server 8765 --directory plans/dalian-20261001/web
```

在浏览器打开 `http://127.0.0.1:8765/`。网页使用 Leaflet 和在线 OpenStreetMap 瓦片，地点和路线数据在 `plans/dalian-20261001/web/map-assets/dalian-map.js`。Netlify 从 `main` 分支发布 `plans/dalian-20261001/web/`，无需构建命令；它不会更新小程序或数据库。
