# 旅行日记小程序

这是项目的原生微信小程序。用微信开发者工具导入本目录，选择「普通编译」，保留现有 Less 编译插件设置。AppID、云托管环境及部署配置见 [云托管 README](../cloudrun/README.md)。

## 页面与功能

- **发现行程**：搜索和筛选整趟旅行，进入详情后按日期查看行程、地图、提醒，支持报名、每日评论、分享及复制。有实际野攀安排的日期显示保险提示和二维码。
- **岩场路书**：按名称或地点搜索岩场，切换区域查看文字介绍和图文线路，点击图片可放大。路书图片存放在数据库，已部署相应版本后更新路书内容无需重新发布小程序。
- **我的收藏**：收藏整趟旅行，保存在当前设备，不在设备间自动同步。
- **个人主页**：设置头像和昵称，查看统计、累计趋势和路线回顾。

## 磕线记录和路线回顾

在活动详情选中日期后，从评论上方进入磕线记录。选择岩场并搜索线路；路书线路目录没有收录时，可手动输入路线名。不需要选择区域。每条记录代表一次攀爬，必填难度（5.7、5.8、5.9 和 5.10a–5.14d）、方式（顶绳或先锋）及结果（视攀、闪攀、红点、粉点、完攀或未完成）；心得可留空。可以删除自己的记录。

个人主页统计以下数据，删除记录后重新计算：

- **活动参加次数**：同一活动任意日期至少有一条自己的磕线记录，按活动去重；报名或评论本身不计入。
- **顶绳和先锋次数**：分别计算对应方式的记录条数。
- **红点路线条数**：先锋视攀、闪攀或红点的路线，按岩场和规范化后的路线名去重；不同手写名称不会自动合并。
- **攀爬次数趋势**：从第一条记录的保存日期开始，每 7 天累计；红线为先锋、蓝线为顶绳、黑线为合计，坐标按数据调整。补录也按保存日期统计。

点击「路线回顾」中的查询按钮，进入独立页面，搜索并选择自己记录过的岩场和路线，不选择区域，也不能手动新增选项；之前手动填写的路线会出现在选项中。查询展示先锋和顶绳次数、最佳成绩及每次记录；有心得时逐条展示原文和记录保存时间。最佳成绩按视攀、闪攀、红点、粉点、完攀、未完成的顺序排列；没有记录时提示「暂时还没有攀爬记录哦～」。左上角返回个人主页。

路线心得直接展示，无需外部总结任务；线路目录维护方法见 [云托管 README](../cloudrun/README.md#磕线记录与个人主页)。

## 数据和更新

`config/cloud.js` 配置微信云托管，`utils/trip-store.js` 读取数据库中的完整行程，社区和攀爬记录通过 `utils/community.js` 访问后端。微信云托管注入可信用户身份；小程序不能直接读取用户的微信号。头像和昵称会展示给查看行程的用户，上线前应填写微信隐私保护指引。

首页、收藏页和分享打开的详情页支持联网更新及下拉刷新；请求失败时保留最近一次成功缓存并提示，首次离线可使用包内行程。云端成功返回空列表时不会恢复包内数据。早期本机反馈不会自动上传。

行程源数据在 `data/`，旅行列表入口是 `data/trips.js`，文字计划在 `../plans/`。新增或修改行程后按 [行程发布流程](../cloudrun/README.md#新增或修改旅行无需重新发版)生成并发布 SQL；保持已有旅行和日期 ID，以保留关联的报名、评论和攀爬记录。实际野攀日期设置 `hasOutdoorClimbing: true`，并遵循 [维护规则](../AGENTS.md)同步保险二维码。

包内封面可在 `static/travel/` 查找；云端封面的来源、地址和生成方式见 [封面说明](../docs/travel/README.md)。新增包内图片、页面或交互需要重新发布小程序；仅更新已经支持的行程、路书和线路目录数据不需要。后端代码变更需单独部署，操作见 [云托管 README](../cloudrun/README.md)。

原 TDesign 模板及早期 `cloudfunctions/` 源码仍保留，但当前注册页面不调用旧云函数。TDesign 遵循 [MIT 协议](https://github.com/TDesignOteam/tdesign-miniprogram-starter/blob/main/LICENSE)。
